Hello! I'm a systems engineer working across networking, embedded systems, robotics, and edge AI.

My background is in large-scale infrastructure and network engineering, but my current work focuses on bringing software, intelligent systems, electronics, and physical hardware together into complete working platforms.

## What I'm Working On

* **Agentic AI & Robotics:** Developing application stacks, middleware, distributed control systems, and edge-AI integrations for robotics and automation at GSN Robotics.

* **Physical AI Systems:** Connecting local AI and LLM workloads with sensors, embedded controllers, telemetry, automation workflows, and deterministic physical control.

* **Embedded Hardware:** Designing custom multilayer PCBs, integrating sensors and microcontrollers, and building prototype hardware using KiCad, Gerbv, FreeCAD, Blender, and 3D printing.

* **Model Integration:** Experimenting with Hugging Face Transformers, LoRA/QLoRA, quantization, and local model deployment for resource-constrained and edge environments.

## Current Architecture Work

I'm developing an agentic orchestration framework designed to connect high-level AI reasoning with deterministic physical and digital execution.

The system separates cognitive workloads from fast control paths, allowing AI agents to coordinate with lower-latency services, embedded devices, sensors, automation systems, and reflex-level endpoints without requiring every action to pass through a large model.

The goal is practical, efficient AI integration with real-world systems.
